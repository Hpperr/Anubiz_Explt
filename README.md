# ANUBIZ_EXPLT v2.0

## Multi-Vector Advanced Exploitation Framework

Professional security testing tool combining OSINT, Network Scanning, and Web Exploitation.

## Features

### OSINT
- Domain information (IP, WHOIS, subdomains)
- IP geolocation and reverse DNS
- Email breach checking (Have I Been Pwned)

### Network
- Port scanning
- Ping scanning
- ARP scanning

### Exploitation
- XSS scanning
- SQL Injection scanning
- LFI scanning
- RCE scanning

### Attack Modes
- Individual module execution
- Full attack chain
- Command line interface
